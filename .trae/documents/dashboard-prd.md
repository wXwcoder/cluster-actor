# Cluster Actor Dashboard - 产品需求文档 (PRD)

## 1. 产品概述

Cluster Actor Dashboard 是一个面向 cluster-actor 分布式系统的可视化监控面板。该面板整合集群（Cluster）、Actor 和 KV Store 三大模块的核心运行数据，提供实时监控、数据可视化和交互式操作能力，帮助运维和开发人员直观掌握系统运行状态。

## 2. 目标用户

- **系统运维人员**：监控集群健康状态、节点运行情况和性能指标
- **后端开发人员**：查看 Actor 实例分布、Grain 类型和 KV 存储状态
- **技术管理人员**：获取系统整体运行状况和关键指标

## 3. 功能需求

### 3.1 集群模块 (Cluster)

#### 3.1.1 基本信息展示
- 数据来源：`/api/cluster/info`
- 展示字段：
  - 集群名称 (cluster_name)
  - 当前节点名称 (node_name)
  - 节点地址 (node_address)
  - 成员数量 (member_count)
  - 运行状态 (is_running)
  - 启动时间 (start_time)

#### 3.1.2 集群状态监控
- 数据来源：`/api/cluster/status`
- 展示字段：
  - 整体健康状态 (status: healthy/degraded/unhealthy)
  - 成员总数 (member_count)
  - 实时成员列表 (members)
  - 数据更新时间戳 (timestamp)
- 状态标识：
  - 🟢 healthy（健康）：所有节点存活
  - 🟡 degraded（降级）：部分节点离线
  - 🔴 unhealthy（异常）：无存活节点

#### 3.1.3 成员信息列表
- 数据来源：`/api/cluster/members`
- 展示字段：
  - 节点名称 (node_name)
  - 节点地址 (address)
  - 存活状态 (alive)
  - 其他元数据信息
- 交互功能：
  - 排序（按名称、地址、状态）
  - 筛选（按存活状态）
  - 悬停显示详细信息

### 3.2 Actor 模块

#### 3.2.1 Actor 类型列表
- 数据来源：`/api/actor/kinds`
- 展示内容：
  - Grain 类型名称列表 (kind_name)
  - 每种类型的实例数量统计
- 可视化：
  - 饼图展示各类型占比
  - 柱状图对比实例数量

#### 3.2.2 Actor 实例列表
- 数据来源：`/api/actor/instances`
- 展示字段：
  - 类型名称 (kind_name)
  - 实例标识 (identity)
  - 所在节点 (node_name)
  - 节点地址 (node_address)
- 交互功能：
  - 按类型筛选
  - 按节点筛选
  - 搜索实例标识
  - 分页显示

### 3.3 KV Store 模块

#### 3.3.1 KV 存储状态
- 数据来源：`/api/kvstore/status`
- 展示字段：
  - 存储状态
  - 键值对数量
  - 存储使用情况
- 健康指标：
  - 正常/警告/异常状态标识
  - 容量使用率进度条

### 3.4 全局功能

#### 3.4.1 数据刷新
- 自动刷新：默认 30 秒自动刷新所有数据
- 手动刷新：点击刷新按钮立即更新
- 刷新状态指示器：显示最后更新时间和加载状态

#### 3.4.2 数据缓存
- 请求结果缓存：减少重复请求
- 缓存策略：30 秒过期时间
- 强制刷新时绕过缓存

#### 3.4.3 响应式设计
- 桌面端（≥1200px）：三列布局，完整信息展示
- 平板端（768px-1199px）：两列布局，压缩部分信息
- 移动端（<768px）：单列布局，折叠次要信息

## 4. 非功能需求

### 4.1 性能要求
- 首屏加载时间 ≤ 2 秒
- 数据请求响应时间 ≤ 1 秒
- 图表渲染时间 ≤ 500ms
- 滚动帧率 ≥ 60fps

### 4.2 可用性要求
- 7×24 小时稳定运行
- 网络异常时显示友好提示
- 数据加载失败时提供重试机制

### 4.3 兼容性要求
- 支持主流浏览器（Chrome 90+、Firefox 88+、Safari 14+、Edge 90+）
- 移动端兼容 iOS Safari 和 Android Chrome

## 5. 界面设计要求

### 5.1 设计风格
- 深色主题，科技感与专业感
- 使用卡片式布局组织信息
- 渐变色和微动效增强视觉层次
- 数据可视化采用统一的配色方案

### 5.2 色彩规范
- 主色调：深蓝 (#0f172a)
- 辅助色：
  - 成功/健康：绿色 (#10b981)
  - 警告/降级：黄色 (#f59e0b)
  - 错误/异常：红色 (#ef4444)
  - 信息/中性：蓝色 (#3b82f6)
- 文字颜色：
  - 主文本：#f8fafc
  - 次要文本：#94a3b8
  - 禁用文本：#64748b

### 5.3 字体规范
- 数字/代码：等宽字体 (JetBrains Mono / Fira Code)
- 标题：现代无衬线字体
- 正文：清晰易读的无衬线字体

## 6. 交互设计要求

### 6.1 加载状态
- 骨架屏加载效果
- 数据刷新时显示 loading 指示器
- 网络错误时显示重试按钮

### 6.2 动画效果
- 卡片入场动画（交错延迟）
- 数值变化时平滑过渡
- 状态切换时颜色渐变
- 悬停时微交互反馈

### 6.3 反馈机制
- 操作成功/失败提示
- 数据刷新完成提示
- 网络断开警告

## 7. 数据流程图

```
用户访问 Dashboard
    ↓
初始化页面布局
    ↓
并发请求 API 数据
    ├── /api/cluster/info
    ├── /api/cluster/status
    ├── /api/cluster/members
    ├── /api/actor/kinds
    ├── /api/actor/instances
    └── /api/kvstore/status
    ↓
数据缓存 (30s)
    ↓
渲染各模块卡片
    ↓
启动自动刷新定时器 (30s)
```
